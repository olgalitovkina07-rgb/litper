те# PLAN.md — план выполнения лабораторной работы №1

## Вариант

**Вариант 4 — «Справочник контактов»**

## Цель

Создать JavaFX-приложение со справочником контактов, реализовать объектную модель из трёх типов, работу с CSV и базовые операции через графический интерфейс.

---

## Этап 0. Проверка окружения

- [ ] Проверить наличие JDK 21.
- [ ] Проверить Gradle Wrapper.
- [ ] Создать/проверить Gradle-проект с Kotlin DSL.
- [ ] Подключить JavaFX.
- [ ] Проверить запуск минимального JavaFX-приложения.

**Результат:** проект собирается и запускается.

---

## Этап 1. Создание модели

Создать:

- [ ] `Contact`
- [ ] `EmergencyContact extends Contact`
- [ ] `CorporateContact extends Contact implements Editable`
- [ ] `Editable`

### Поля Contact

- [ ] `name`
- [ ] `phone`
- [ ] `email`
- [ ] `organization`

### Поля CorporateContact

- [ ] `position`
- [ ] `internalNumber`

### EmergencyContact

- [ ] является read-only;
- [ ] не реализует `Editable`;
- [ ] не может быть изменён через GUI.

### Editable

Использовать контракт:

```java
List<String> validate();
```

Для корректного объекта возвращается пустой список ошибок.

**Результат:** иерархия из трёх типов работает, объекты можно создать и проверить.

## Этап 2. Хранение контактов

- [ ] Создать сервис для работы с контактами.
- [ ] Хранить контакты в понятной коллекции.
- [ ] Реализовать получение всех контактов.
- [ ] Реализовать добавление.
- [ ] Реализовать замену/редактирование.
- [ ] Не помещать бизнес-логику в JavaFX-контроллер.

**Результат:** GUI сможет работать с контактами через сервис.

---

## Этап 3. CSV

Создать:

- [ ] `CsvLoader`
- [ ] `CsvWriter`

Формат:

```text
type;name;phone;email;organization;position;internalNumber
```

Примеры:

```text
corporate;Иван Иванов;+79990000000;ivan@example.com;ООО Ромашка;Инженер;123
emergency;Пожарная служба;101;;МЧС;;
```

### Загрузка

- [ ] Читать файл построчно.
- [ ] Пропускать заголовок.
- [ ] Разбирать строки.
- [ ] Создавать нужный тип по `type`.
- [ ] Битую строку пропускать.
- [ ] Ошибки отдельных строк не должны останавливать загрузку всего файла.
- [ ] Ошибку открытия/чтения файла передавать в GUI.

### Сохранение

- [ ] Сохранять заголовок.
- [ ] Сохранять все контакты.
- [ ] Корректно записывать оба типа.
- [ ] Не терять дополнительные поля `CorporateContact`.

**Результат:** можно загрузить и сохранить справочник в CSV.

## Этап 4. JavaFX GUI

Создать простое окно со следующими элементами:

- [ ] таблица контактов;
- [ ] «Загрузить CSV»;
- [ ] «Сохранить CSV»;
- [ ] «Добавить»;
- [ ] «Изменить».

### Добавление

- [ ] Через кнопку «Добавить» создавать только `CorporateContact`.
- [ ] Показывать диалог ввода полей.
- [ ] При некорректных данных показывать ошибку.

### Редактирование

- [ ] Если выбран `CorporateContact`, кнопка «Изменить» активна.
- [ ] Если выбран `EmergencyContact`, кнопка «Изменить» заблокирована.
- [ ] После изменения обновлять таблицу.

### Ошибки

- [ ] Нет выбранного контакта → понятное сообщение.
- [ ] Ошибка CSV → понятное сообщение.
- [ ] Некорректные данные → понятное сообщение.
- [ ] Ошибка сохранения → понятное сообщение.

**Результат:** все минимальные GUI-требования методички выполнены.
